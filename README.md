# carazcht

Home of imagination. (Good imagination.)

This project is a small digital storybook built as a single-page reading experience.

## Run locally

From the project folder:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Customize

- Edit the chapter list in `script.js`
- Change the visual theme in `styles.css`
- Update the page copy in `index.html`
